# Harako-RNAseq v0.2.0-beta.1

Harako-RNAseq v0.2.0-beta.1 is the first source-available public beta of the
local, single-user bulk RNA-seq application.

## Highlights

- A guided Streamlit GUI with project, sample, reference, advanced, and summary
  steps.
- Verified Windows Docker Desktop and Ubuntu/Linux Docker workflows.
- Session-isolated drafts and immutable run-local configuration for
  reproducible resume and recovery.
- FASTQ discovery, paired-end matching, condition normalization, and supported
  SRA/ENA acquisition.
- Canonical, SHA256-verified Ensembl presets for human, mouse, and rat.
- fastp preprocessing and Salmon transcript quantification.
- Gene-level counts and descriptive TPM through tximport. DESeq2 uses counts,
  not TPM.
- A minimum differential-expression eligibility gate and explicit QC-only mode
  for one-condition or under-replicated designs.
- Optional enrichment only when inferential differential-expression statistics
  are available.
- A self-contained HTML report with reference, tool, run, and analysis
  provenance.
- CI checks for Linux, Windows path behavior, Docker, governance, scientific
  contracts, smoke execution, and report integrity.
- A verified Trivy 0.70.0 candidate scan with explicit Critical/High
  dispositions and exact corresponding-source archives for identified R
  packages.
- Planned GHCR images with BuildKit SBOM/provenance and GitHub digest
  attestation.

## Scientific scope

Differential-expression mode requires at least two conditions and at least two
samples in every condition. Designs below that minimum run in QC-only mode
without p-values, adjusted p-values, inferential contrasts, or enrichment.
This software gate is not a power calculation and does not establish biological
independence or an adequate experimental design.

## Known limitations

- This is a public beta, not a broad production-readiness claim.
- Operation is local and single-user; hosted multi-user deployment is not
  supported.
- The container architecture is `linux/amd64`.
- macOS is not yet verified.
- Apple Silicon is not supported natively.
- STAR, HISAT2, and BAM-producing alignment workflows are not implemented.
- ATAC-seq is not supported.
- The minimum replicate gate is not a power calculation.
- Custom references receive local provenance but are less strongly verified
  than the built-in manifest bundles.
- Initial source builds can be slow because they install R and Bioconductor
  dependencies.
