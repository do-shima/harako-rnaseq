# v0.3.0-beta.1 release plan

Status: published on `2026-08-12` as the current public beta. The annotated
`v0.3.0-beta.1` tag, GitHub prerelease, exact GHCR image, and moving `beta`
image are available; no `latest` image was published for this prerelease.

## Scope

The beta adds a vendor-neutral agent-ready CLI with deterministic plans,
explicit approval, existing-pipeline execution, run introspection, sanitized
context, and isolated post-analysis workspaces. MCP and Codex App Server
integration are deferred.

## Release criteria

- [x] Complete and documented agent CLI contracts.
- [x] Deterministic plan ID and approval hash covering all execution-relevant
  data.
- [x] No execution without exact explicit approval.
- [x] Successful Windows and Linux/Docker qualification.
- [x] Existing Streamlit GUI and v0.2 configuration and frozen-Run behavior
  remain regression-free.
- [x] Real R/DESeq2 fixtures, differential smoke, QC-only smoke, and real
  Snakemake dry-run completed.
- [x] One controlled real-data pilot completed.
- [x] Post-analysis isolation from frozen Harako runs verified.
- [x] No raw FASTQ sequence exposure in inspection, plans, context, or logs.
- [x] Documentation, examples, compatibility notes, and exit-code contracts
  completed.

## Post-release beta adoption goal

Obtain feedback from at least two external pilot users after publication. This
is an adoption and usability goal, not a blocker for the qualified prerelease.

## Development qualification status

- The command-level agent smoke covers `inspect-input`, `propose-samples`, an
  explicit condition map, `plan`, `validate-plan`, `dry-run`, refused and
  exactly approved `execute`, `status`, `artifacts`, `context`, and
  `post-analysis-init`.
- Differential two-by-two and explicitly approved QC-only smoke paths pass on
  the Windows host. The smoke confirms deterministic hashes, no inferred
  conditions, sanitized JSON, typed artifacts, and unchanged core Run files
  after post-analysis initialization.
- Focused agent, eligibility, and UI configuration qualification passes with
  55 tests passed and one intentional POSIX-only skip on Windows.
- Canonical host qualification passes on Python 3.9.13 with 351 tests passed,
  11 skipped, and two non-blocking dependency warnings.
- Canonical Docker qualification passes on Python 3.11.14 with 360 tests
  passed and two platform/environment-specific skips. The real R/DESeq2
  fixture modes, agent smoke with a real Snakemake dry-run, existing scientific
  smoke, self-contained report verification, strict runtime-license inventory,
  and UI diagnostics all pass.
- One controlled local real-data pilot completed the full public command
  sequence with 12 paired-end mouse samples in four explicitly assigned groups,
  checksum-verified GRCm39 release-113 references, six approved pairwise
  contrasts, and enrichment. Status, typed artifacts, sanitized context, the
  self-contained report, and an isolated descriptive post-analysis summary
  were verified. The pilot found and corrected an MA-plot inventory path and
  missing pairwise contrast details in context; focused regressions cover both.
- The 12 checksum-pinned reference SHA256 values remain unchanged, and no
  production reference download is part of the agent smoke.

Release closeout completed the version metadata, `CITATION.cff` date, final
image qualification, security dispositions, annotated tag, GHCR publication,
SBOM/provenance/attestation publication, and GitHub prerelease.
