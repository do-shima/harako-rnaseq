# Public-beta feedback

Harako-RNAseq does not collect telemetry. Processing remains local except when
the user explicitly requests reference or SRA/ENA downloads.

Use the repository's **Public-beta feedback** issue form after a beta run. It
asks for platform, Docker version, input type, read layout, reference, estimated
scale, completion state, elapsed time, disk use, usability, documentation
quality, and sanitized support-bundle availability.

GitHub Issues are public. Never attach FASTQ files, patient data, credentials,
identifiable sample names, confidential reports, or unsanitized logs. Replace
sample identifiers and inspect a support bundle before sharing it.

The beta rollout targets a small group of Windows and Ubuntu/Linux users with a
mix of RNA-seq experience. The initial operational goal is at least three
unaided report completions before broader promotion.
