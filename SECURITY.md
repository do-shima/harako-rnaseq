# Security Policy

## Supported Versions

Security fixes are provided for the current public beta line. Users should
upgrade to the most recent beta patch before reporting a vulnerability.

| Version | Supported |
| --- | --- |
| 0.3.x beta | Yes |
| 0.2.x beta | No |
| 0.1.x and earlier | No |

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public GitHub issue.

Use GitHub's private vulnerability reporting feature for this repository. If
that feature is unavailable, contact the repository owner through their public
GitHub profile to request a private reporting channel. Do not include sensitive
details in the initial public contact.

Security reporting is not a route for commercial-license inquiries. Commercial
licensing questions should follow
[COMMERCIAL_LICENSE.md](COMMERCIAL_LICENSE.md).

Include the affected Harako-RNAseq version or commit, the deployment platform,
the security impact, reproduction steps, and any known mitigation. Remove
sample identifiers, credentials, access tokens, FASTQ data, and other
confidential information.

Maintainers will acknowledge a private report, assess its impact, and coordinate
disclosure and a fix as capacity permits.

Ordinary analysis failures, scientific questions, documentation problems, and
feature requests belong in GitHub Issues and are not security reports.
