# Support

## Supported Use

Harako-RNAseq is intended for:

- local, single-user analysis;
- small-to-medium bulk RNA-seq datasets; and
- Windows, Linux, and macOS systems running Docker.

Ordinary project support covers use permitted for academic, educational, public
research, and other noncommercial purposes under the
[PolyForm Noncommercial License 1.0.0](LICENSE). Commercial licensing questions
should follow [COMMERCIAL_LICENSE.md](COMMERCIAL_LICENSE.md).

Harako-RNAseq is not yet a hosted, shared, multi-user service. Cluster
deployment, regulated clinical use, and unattended production service operation
are outside the current support scope.

## Getting Help

Search existing GitHub Issues before opening a new issue. Use the bug report
form for reproducible failures, the documentation form for unclear or incorrect
documentation, and the feature request form for proposed changes.

GitHub Issues are public. They must not contain confidential data, FASTQ files,
patient information, credentials, or identifiable sample data.

A useful bug report includes:

- the Harako-RNAseq version or commit;
- operating system and version;
- Docker version;
- the launch command;
- the pipeline stage that failed;
- a support bundle or sanitized logs; and
- the sample table structure with sensitive identifiers replaced.

Never upload FASTQ files, credentials, patient information, confidential sample
identifiers, or other sensitive data. Use minimal synthetic examples where
possible.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md).
