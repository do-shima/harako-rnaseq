Harako-RNAseqの導入

WindowsまたはLinuxでリリース版をビルドするか、公開されている場合はバージョン指定のGHCRイメージを利用します。

v0.3.0-beta.1を入手 概要に戻る

導入前の確認

必要なソフトウェア

Git、Linuxコンテナを実行できるDocker、just、127.0.0.1:8501へ接続できるブラウザを用意します。Python、R、Snakemake、fastp、Salmonをホスト側へ個別に導入する必要はありません。

動作確認済み環境

WindowsのDocker DesktopとUbuntu/LinuxのDockerで動作を確認しています。イメージはlinux/amd64向けで、Apple Siliconのネイティブ実行には対応していません。

CPUとメモリ

小規模から中規模の解析では、4コア以上のCPUとおおむね8～16 GBのメモリが目安です。必要量はサンプル数、参照配列のサイズ、行列の大きさによって増加します。

ディスク容量：入力FASTQ、展開後のfastp中間ファイル、Salmon indexと定量結果、キャッシュされた参照バンドル、Run出力、約1.2 GBのDockerイメージ、Dockerのビルドレイヤーに必要な容量を確保してください。Harako-RNAseqは中間ファイルを自動削除しません。

Windows PowerShell

Docker DesktopをLinuxコンテナモードで起動します。リポジトリをcloneし、対象の公開ベータ版タグを選択してから、ローカルでDockerイメージをビルドします。

git clone https://github.com/do-shima/harako-rnaseq.git
Set-Location harako-rnaseq
git checkout v0.3.0-beta.1
just build-ps
just app-ps

自身のデータを使用する場合は、ホスト側のディレクトリを明示します。

$env:INPUT = "D:\rna\input"
$env:OUT = "D:\rna\output"
just app-ps

Windowsのバインドマウントを確認するときはPowerShellを使用してください。入力ディレクトリは読み取り専用でマウントされ、出力は指定した出力ディレクトリ以下に保存されます。

Ubuntu/Linux

Docker Engineを導入して起動し、リポジトリをcloneして対象のリリース版を実行します。

git clone https://github.com/do-shima/harako-rnaseq.git
cd harako-rnaseq
git checkout v0.3.0-beta.1
just build
just app

マウント先を明示すると、解析データをリポジトリの外に保存できます。

INPUT=/data/rna/input OUT=/data/rna/output just app

どちらの環境でも、起動後にhttp://127.0.0.1:8501を開きます。Harako-RNAseqはローカル・単一ユーザー向けです。このポートを外部公開してマルチユーザーサービスとして運用しないでください。

バージョン指定のGHCRイメージ

GitHub Container Registryでパッケージが公開されている場合は、更新されるbetaタグではなく、バージョン指定のリリースタグを使用します。

docker pull ghcr.io/do-shima/harako-rnaseq:v0.3.0-beta.1
IMAGE=ghcr.io/do-shima/harako-rnaseq:v0.3.0-beta.1 just app

Windows PowerShell：

docker pull ghcr.io/do-shima/harako-rnaseq:v0.3.0-beta.1
$env:IMAGE = "ghcr.io/do-shima/harako-rnaseq:v0.3.0-beta.1"
just app-ps
イメージが公開されていない場合やpullできない場合は、上記の手順でソースからビルドしてください。

マウント、初回ビルド時間、ポート転送、プライバシー、対応環境の詳細は、GitHubの導入ドキュメントを参照してください。
