Harako-RNAseq

ローカル環境向けのバルクRNA-seq解析GUI

Harako-RNAseqは、再開可能なSnakemakeワークフローを単一のDockerイメージにまとめたRNA-seq解析GUIです。入力データと解析結果は、指定したローカルディレクトリに保存されます。

Docker RNA-seqパイプライン

前処理からレポートまでを一貫して実行

fastpでリードを前処理し、Salmonで転写産物を定量します。tximportで遺伝子レベルのcountsとTPMを作成し、最小反復条件を満たす場合に限ってDESeq2による遺伝子発現変動解析（differential expression analysis）を実行します。

  1. fastp
    リード前処理とサンプル別QC。
  2. Salmon
    選択したSalmon indexを用いた転写産物レベルの定量。
  3. tximport
    遺伝子レベルのcountsと、発現量指標としてのTPMを出力。
  4. DESeq2
    最小反復条件を満たす場合に発現変動解析を実行。

解析条件に応じた統計処理

QC-onlyモード

DESeq2による発現変動解析には、2条件以上、かつ各条件に2サンプル以上が必要です。これはソフトウェア上の最小要件であり、統計的検出力を評価するものではありません。入力内容が有効でも、この最小反復条件を満たさない場合はQC-onlyモードで処理を継続し、p値や調整p値は算出・出力しません。

countsとTPMの役割

DESeq2には遺伝子レベルのcountsを入力します。TPMは遺伝子レベルの発現量指標として出力しますが、DESeq2には使用しません。

参照プリセット

組み込みのヒト、マウス、ラットのEnsembl参照は、登録済みのSHA256チェックサムで検証します。参照配列とアノテーションの由来情報は各Runに記録されます。

FASTQとSRA/ENA

single-end / paired-end FASTQに加え、SRA/ENAのアクセッション番号からデータを取得する機能も利用できます。

自己完結型レポート

結果は外部のWebリソースに依存しないHTMLレポートにまとめられます。解析後も単一ファイルとして閲覧・共有できます。

再現性と再開

Run開始時に、設定、サンプル表、解析モードの判定情報、参照配列とアノテーションの由来情報を保存し、その後は変更しません。Snakemakeにより、中断した処理を同じ設定で再開できます。
