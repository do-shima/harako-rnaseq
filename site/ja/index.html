Harako-RNAseq

ローカル環境で、再現可能なバルクRNA-seq解析をわかりやすく

Harako-RNAseqは、再開可能なSnakemakeワークフローを1つのDockerイメージにまとめたRNA-seq解析GUIです。WindowsのDocker DesktopとUbuntu/LinuxのDockerに対応し、研究データと解析結果を手元のワークステーションで管理できます。

Docker RNA-seqパイプライン

前処理からレポートまでを一貫して実行

fastpでリードを前処理し、Salmonで転写産物を定量します。tximportで遺伝子レベルのcountsとTPMを作成し、解析条件を満たす場合に限ってDESeq2による差次的発現解析へ進みます。

  1. fastp
    リード前処理とサンプル別QC。
  2. Salmon
    アラインメント不要の転写産物定量。
  3. tximport
    遺伝子countsと記述的TPM。
  4. DESeq2
    条件を満たす設計のみ差次的発現解析。

QC-onlyモード

差次的発現解析には2条件以上、かつ各条件に有効な2サンプル以上が必要です。条件を満たさない構造上有効な設計はQC-onlyとして継続し、p値や調整p値を作りません。

countsとTPMの役割

DESeq2に渡すのは遺伝子レベルのcountsです。TPMは発現量を記述する出力として保存し、差次的発現解析の入力には使いません。

参照プリセット

human、mouse、ratのEnsembl参照をSHA256で固定しています。参照配列と注釈の由来はRunごとに記録されます。

FASTQとSRA/ENA

single-end / paired-end FASTQに加え、対応するSRA/ENAアクセッション取得フローを利用できます。

自己完結型レポート

結果は外部Web資源を必要としないHTMLレポートにまとめられます。解析後も単一ファイルとして閲覧・共有できます。

再現性と再開

Run開始時の設定、サンプル表、analysis plan、参照由来情報を固定します。Snakemakeにより、中断した処理を同じ設定で再開できます。
