Install Harako-RNAseq

Build from the release source on Windows or Linux, or use the exact GHCR image when it is publicly available.

Get v0.2.0-beta.1 Back to overview

Before you begin

Required software

Install Git, Docker with a running Linux container engine, just, and a browser that can reach 127.0.0.1:8501. Native Python, R, Snakemake, fastp, and Salmon installs are not required.

Verified platforms

Windows with Docker Desktop and Ubuntu/Linux with Docker are verified. The image is linux/amd64; native Apple Silicon support is not available.

Planning resources

Four or more CPU cores and roughly 8–16 GB RAM are useful for small-to-medium studies. Actual needs grow with sample count, reference size, and matrix dimensions.

Disk planning: reserve space for source FASTQ files, uncompressed fastp intermediates, Salmon indexes and quantification, cached reference bundles, run artifacts, the approximately 1.2 GB image, and Docker build layers. Harako does not automatically delete intermediates.

Windows PowerShell

Start Docker Desktop in Linux-container mode. Clone the repository, select the exact public-beta tag, and launch the local Docker build:

git clone https://github.com/do-shima/harako-rnaseq.git
Set-Location harako-rnaseq
git checkout v0.2.0-beta.1
just build-ps
just app-ps

For real studies, set explicit host directories before launching:

$env:INPUT = "D:\rna\input"
$env:OUT = "D:\rna\output"
just app-ps

Use PowerShell when diagnosing Windows bind-mount paths. The input directory is mounted read-only; outputs are written below the selected output directory.

Ubuntu and Linux

Install and start Docker Engine, then clone and launch the exact release source:

git clone https://github.com/do-shima/harako-rnaseq.git
cd harako-rnaseq
git checkout v0.2.0-beta.1
just build
just app

Optional explicit mounts keep study data outside the repository:

INPUT=/data/rna/input OUT=/data/rna/output just app

On either platform, open http://127.0.0.1:8501. Harako is a local, single-user application; do not expose the port as a hosted multi-user service.

Exact-version GHCR image

If the package is public in GitHub Container Registry, prefer the immutable release tag over the moving beta channel.

docker pull ghcr.io/do-shima/harako-rnaseq:v0.2.0-beta.1
IMAGE=ghcr.io/do-shima/harako-rnaseq:v0.2.0-beta.1 just app

Windows PowerShell:

docker pull ghcr.io/do-shima/harako-rnaseq:v0.2.0-beta.1
$env:IMAGE = "ghcr.io/do-shima/harako-rnaseq:v0.2.0-beta.1"
just app-ps
Image availability and public package visibility must be confirmed in GHCR. If the pull fails because the package is unavailable, use the source-build instructions above.

For mounts, first-build expectations, port forwarding, privacy guidance, and current platform status, read the full installation documentation.
