Harako-RNAseq

Graphical and reproducible bulk RNA-seq analysis for local workstations

Harako-RNAseq is an RNA-seq GUI that brings a resumable Snakemake workflow into one Docker image. It runs locally for a single user on Windows with Docker Desktop or Ubuntu/Linux with Docker, keeping study inputs and results on the workstation.

Reproducible transcriptomics workflow

From reads to reviewable results

The Docker RNA-seq analysis path combines established tools while preserving the run configuration, provenance, logs, and versions needed to understand and resume an analysis.

  1. fastp
    Read preprocessing and per-sample QC.
  2. Salmon
    Transcript-level, alignment-free quantification.
  3. tximport
    Gene counts for modeling and descriptive gene TPM.
  4. DESeq2
    Differential expression only for eligible designs.

Designed for honest local analysis

Differential or QC-only

DESeq2 differential expression requires at least two conditions and at least two valid samples in every condition. Unsupported but structurally valid designs continue in explicit QC-only mode without fabricated p-values.

References with provenance

Checksum-pinned Ensembl presets cover human, mouse, and rat. Custom transcript FASTA, genome FASTA, and GTF inputs are also supported when the researcher needs another reference.

FASTQ or SRA/ENA

Use local single-end or paired-end FASTQ data, or the supported SRA/ENA acquisition workflow. Source accession metadata is retained for review.

Counts and TPM

tximport produces gene-level counts and TPM. DESeq2 uses counts, never TPM; TPM remains a descriptive abundance output.

Portable reporting

Every completed run targets a self-contained HTML report at report/report.html, with no required web assets or analytics calls.

Frozen and resumable

Run-local inputs are immutable. Snakemake preserves resumability while the frozen analysis plan remains the authority for differential versus QC-only behavior.
